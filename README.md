# Nube ☁️

Widget flotante para Windows: una nubecita en el borde de la pantalla que te avisa de tus reportes y reuniones, guarda tus mensajes frecuentes y abre tus herramientas rápidas.

## Descargar

👉 **[Última versión](https://github.com/Luchito1099/nube-releases/releases/latest)** → descarga `Nube-Setup-<versión>.exe` y ábrelo.

- Windows 10/11 de 64 bits.
- Si aparece **"Windows protegió tu PC"**: *Más información* → *Ejecutar de todas formas*.
- Con el instalador, **las actualizaciones llegan solas**: la nube te avisa cuando hay una versión nueva.
- `Nube-portable` funciona sin instalar, pero no se actualiza sola.

Este repositorio solo contiene los instaladores.
